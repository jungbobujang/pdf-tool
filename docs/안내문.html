PDF 작업실

설치 없이, 파일을 올리지 않고 PDF를 고치는 무료 웹 도구

주소https://edit.up.railway.app엣지 · 크롬 · 웨일에서 여세요. 한 번 연 뒤에는 인터넷이 없어도 작동하고, [바탕화면에 설치]로 아이콘을 만들 수 있어요.

1할 수 있는 일 6가지

  • 편집 · 합치기여러 PDF 합치기, 쪽 순서 바꾸기 · 돌리기 · 빼기, 나눠 저장
  • 사진 → PDF휴대폰 사진 · 스캔한 활동지를 한 PDF로 (아이폰 사진도)
  • PDF → 사진원하는 쪽만 PNG · JPG로, 한 쪽은 복사해 PPT · 한글에 붙이기
  • 꾸미기쪽번호 · 워터마크 · 서명과 도장 넣기
  • 용량 줄이기"공문 10MB"처럼 목표에 맞춰 줄이기 (글자는 그대로)
  • 보안암호 걸기 · 풀기, 이 파일에 걸린 제한 보기

2왜 안전한가요?

  • 파일이 컴퓨터 밖으로 나가지 않아요. 모든 처리는 내 브라우저 안에서 끝나고, 서버에는 파일을 받는 기능이 아예 없어요.
  • 인터넷을 꺼도 작동해요. 보낼 곳이 없다는 뜻이에요.
  • 브라우저가 연결을 막아요. 이 사이트 밖으로 데이터를 보낼 수 없게 규칙(CSP)을 걸어 두었어요.
  • 수집하는 정보가 없어요. 쿠키 · 통계 · 광고 · 외부 스크립트가 없어요.
  • 원본을 바꾸지 않아요. 결과는 항상 새 파일로 저장돼요.

3직접 확인하는 법

  1. 와이파이 끄고 해 보기 — 사이트를 한 번 연 뒤 와이파이를 끄고 PDF 두 개를 합쳐 보세요. 그대로 저장돼요.
  2. Network 탭 보기 — F12 → Network 탭을 열고 파일을 넣어 보세요. 파일을 보내는 줄이 생기지 않아요.
  3. 규칙 읽기 — 사이트의 "직접 확인하는 법" 페이지에 브라우저에 거는 규칙이 쉬운 말로 나와 있어요.

4자주 하는 작업

공문 첨부용 10MB 만들기첫 화면 아래 [공문 첨부용 10MB 만들기] → PDF 넣기 → [줄이기] → [바로 저장]
스캔본 정리해서 합치기PDF 여러 개 넣기 → 빈 쪽 · 크기 다른 쪽 안내 확인 → 끌어서 순서 맞추기 → [바로 저장]
학습지 사진을 PDF로사진을 한꺼번에 끌어다 놓기 → 순서 · 용지 고르기 → [바로 저장]
저장한 파일은 보통 "다운로드" 폴더에 있어요. 안 보이면 Ctrl+J. 결과물은 저장 후 열어서 확인해 주세요.
