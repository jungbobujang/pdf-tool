PDF 작업실 ← 작업실로 돌아가기

개인정보 안내

마지막 갱신: 2026년 10월 5일

1. 수집하는 정보

이름 · 이메일은 받지 않습니다. PDF 작업실은 스쿨 선생님 전용 도구라, 스쿨 도구함의 [열기]로 들어올 때 스쿨이 만든 가명 번호(사람 · 학교, 실제 번호로 되돌릴 수 없음)만 받아 통행증 쿠키에 담습니다. 이 번호는 서버 파일이나 데이터베이스에 저장하지 않고, 통행증은 8시간 뒤 끝납니다. 서버 메모리에는 한 번 쓴 입장권 번호만 3분 동안 두어 같은 입장권을 두 번 못 쓰게 합니다. 서버 기록(로그)에는 들어오기 성공 · 실패와 실패 이유의 종류만 남깁니다.

2. 파일 처리

넣은 PDF와 사진은 사용하는 브라우저 안에서만 처리되며, 서버나 다른 곳으로 전송되지 않습니다. 서버에는 파일을 받는 기능이 없습니다.

도장 만들기에 쓴 이름 · 부서 · 날짜도 이 화면 안에서만 그림으로 만들며 보내지 않습니다. 도장 글꼴은 이 사이트에서 받는데, 글꼴마다 글자 수백 개씩 묶은 조각으로 나뉘어 있어 화면에 쓰는 글자가 든 조각만 받습니다(어떤 조각을 받았는지로 이름을 알 수는 없습니다).

3. 이 브라우저에 저장되는 것

화면 설정(마지막으로 연 도구, 사용법 패널 접힘, 저장 옵션 등)은 이 브라우저의 저장소(localStorage)에만 저장됩니다. 직접 등록한 서명 · 도장 그림과 도장 만들기에서 [내 도장에 보관] · [PDF에 찍기]를 누른 도장(그림과 고른 설정 · 새긴 글자)은 다음에 다시 쓸 수 있도록 이 브라우저(IndexedDB)에만 보관되며, 언제든 지울 수 있습니다(공용 컴퓨터면 설정의 [모두 지우기]). 넣은 PDF와 사진은 기본적으로 저장되지 않습니다. 2026년 9월 30일부터 오프라인용 파일(앱 화면 · 글꼴 · 라이브러리)을 미리 받아 두지 않으며, 예전에 받아 둔 것은 스스로 지워집니다. 이미 연 화면은 와이파이를 꺼도 작동하지만, 새로고침하면 스쿨 도구함에서 다시 열어야 합니다.

설정에서 "브라우저를 닫아도 작업 이어하기"를 직접 켠 경우에만, 편집 · 합치기에 넣은 PDF와 순서 · 회전 상태가 이 브라우저(IndexedDB)에 저장됩니다. 이 기능을 끄거나 설정의 [모두 지우기]를 누르면 바로 지워지며, 공용 컴퓨터에서는 켜지 않기를 권합니다.

4. 쿠키 · 통계 · 외부 스크립트

쿠키는 통행증 하나(pdf_pass, 가명 번호와 끝나는 시각, 8시간)만 씁니다. 방문 통계, 광고, 외부 스크립트는 사용하지 않습니다. 들어올 때 스쿨의 공개 키를 받아 오는 요청 말고는 다른 곳과 주고받지 않습니다. 모든 화면 · 글꼴 · 라이브러리는 이 사이트에서 제공하며, 브라우저 보안 규칙(CSP)으로 다른 곳과의 연결을 막아 둡니다. 자세한 내용은 직접 확인하는 법을 보세요.

5. 의견 보내기

[의견 보내기]는 외부 설문 페이지를 새 창으로 여는 것뿐이며, 파일이나 화면 내용은 함께 전송되지 않습니다. 설문 페이지에서 적은 내용은 그 설문 서비스의 정책을 따릅니다.
