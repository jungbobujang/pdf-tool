직접 확인하는 법

"파일이 밖으로 안 나간다"는 말을 믿지 않아도 돼요. 아래 세 가지로 누구나 직접 확인할 수 있어요.

1

와이파이를 끄고 해 보기

  1. 이 사이트를 한 번 열어 둡니다(처음 열 때 필요한 파일을 브라우저에 받아 둬요).
  2. 와이파이를 끄거나 랜선을 뽑습니다.
  3. PDF 두 개를 넣고 [바로 저장]을 누르세요. 그대로 합쳐져서 저장돼요.

인터넷이 없으면 화면 아래 안심 문구 옆에 "지금 인터넷 없이 작동 중"이 켜져요. 인터넷이 없는데도 된다는 건, 파일을 보낼 곳이 없다는 뜻이에요.

2

F12 → Network 탭에서 보기

  1. 이 사이트에서 F12(맥은 ⌘+Option+I)를 눌러 개발자 도구를 엽니다.
  2. 위쪽의 Network(네트워크) 탭을 누르고, 목록을 비웁니다(🚫 단추).
  3. PDF를 넣고 편집 · 저장해 보세요. 파일을 보내는 새 줄이 생기지 않아요.

처음 열 때는 화면 · 글꼴 · 라이브러리를 받는 줄이 보여요. 모두 이 사이트에서 받는 것이고, 파일을 넣은 뒤에는 새 줄이 없어요(한글 워터마크를 처음 쓸 때 글꼴 한 개를 받는 것 말고는).

3

이 사이트가 브라우저에 거는 규칙(CSP)

이 사이트는 화면을 보낼 때 브라우저에게 "이 규칙을 지켜라"라는 약속(Content-Security-Policy)을 함께 보내요. 브라우저가 직접 지키는 규칙이라 사이트 코드가 어기려 해도 막혀요.

확인하는 법: F12 → Network 탭 → 맨 위 문서(주소) 줄을 누르고 → Headers의 content-security-policy를 보세요. 위 목록과 같아요.

이 도구는 원본 파일을 바꾸지 않습니다. 결과물은 저장 후 열어서 확인해 주세요.
